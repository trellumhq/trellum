Data retention

Your reports and the files you upload are kept for as long as you use them. Nothing here expires data anyone is still working with: built output stays until someone deletes the report, and an uploaded file stays as long as a data source points at it. What these windows govern is what is left behind afterwards — a file nothing references any more, or the output of a studio that was deleted. Reports, schedules and history are never touched.
